## useMediaQuery
A React hook that subscribes to CSS media query changes.

### Installation
<InstallCommand url="https://registry.rchoudhury.dev/r/use-media-query.json" />

### Parameters
- `query: string`: Any valid CSS media query, such as `"(max-width: 768px)"`.

### Returns
- `boolean`: `true` when the media query currently matches.

### Usage
```tsx
import { useMediaQuery } from "@/hooks/use-media-query";

export function MyComponent() {
  const isMobile = useMediaQuery("(max-width: 768px)");
  const isDark = useMediaQuery("(prefers-color-scheme: dark)");
  const isLandscape = useMediaQuery("(orientation: landscape)");

  return (
    <div>
      {isMobile ? <MobileView /> : <DesktopView />}
    </div>
  );
}
```

### Notes
- The hook uses `useSyncExternalStore`, which keeps subscription behavior consistent with React's concurrent rendering model.
- On the server it returns `false` until hydration, so plan for that initial value when rendering responsive UI.
- It works well for viewport, color scheme, motion preference, and orientation queries.
